# PhishVille — Landing Page Starter

Fresh React + Vite foundation for the PhishVille landing page. This phase includes only the project setup and homepage; Phaser gameplay and the full Teacher Portal are intentionally not included yet.

## Requirements

- Node.js 18 or newer
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Included in this phase

- Responsive React landing page
- Supplied PhishVille city artwork in `public/images/phishville-city.jpg`
- Home, Story Mode and Teacher Portal navigation
- Day/night appearance toggle
- Story Mode and Teacher Portal notice dialogs (the destinations will be connected when those parts are built)
- Responsive mobile navigation and reduced-motion support

## Next integration step

Once the homepage is approved, connect the Story Mode and Teacher Portal controls to their real pages/components. Phaser and gameplay should be added in a later phase, not to this starter yet.
